# Chrome Web Store listing — Pathira

## Short description
Capture clicks and screenshots across browser tabs, then turn them into clear step-by-step guides.

## Detailed description
Pathira helps you document browser workflows while you do the work.

Start a capture, move through normal browser tabs, and click through your process. A persistent side panel records each action in order with a screenshot, page context, and a readable description of what was clicked. When you finish, import the steps into the companion guide editor to refine and share the walkthrough.

### Core features
- Capture ordered clicks across browser tabs
- Take a compressed screenshot for each step
- Highlight the clicked element
- Keep a live capture timeline in Chrome's side panel
- Include page titles and links for context
- Import captured steps into editable guides
- Keep capture data on your device

### Intended use
Use Pathira to document authorized workflows, onboarding instructions, internal processes, support guides, and software training. Screenshots may include information visible in your browser, so avoid capturing confidential or sensitive data unless you are authorized to do so.
